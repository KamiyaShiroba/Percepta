# Percepta

HSV 还是 HLS？不如试试 OKLCH！

OKLCH 是一种基于人类视觉感知设计的现代色彩空间，它让颜色的明暗、鲜艳度和色调可以独立调整，比传统的 RGB 和 HSL 更符合人眼感受。简单来说，**用它调色就像调节滑块一样直观**——你想要单纯调亮某个颜色时，它的鲜艳度和色调绝对不会跟着乱变，彻底告别了传统 HSL 里“黄色看起来比蓝色刺眼、绿色比紫色暗淡”的视觉不均匀问题。

要是还不懂？那...藏色！这就是为藏色量身定制的色彩空间，这样总懂了吧？

没错！正因为 OKLCH 的这种特性实在是太美味了，让作者垂涎欲滴（大雾），但是囿于 CSP 没有这个功能，于是做了这个小工具。是一个给 CLIP STUDIO PAINT（下文简称 CSP）用的外置取色器，对，仅此而已。

Percepta，取自 **Perception（感知）** 和 **Chroma（彩度）**。不被数学计算蒙蔽，只遵循人类眼球最真实的感知。

作者尽可能让它的功能和 CSP 的接近，包括操作方式等等等等，甚至能够直接盖到 CSP 上使用。所以不止 OKLCH，CSP 色环和滑块里该有的颜色模式一个也没有落下，全部都可以实时调整并和 CSP 同步！

> 目前只支持 Windows。

## 怎么用？

先去 [Releases](https://github.com/KamiyaShiroba/Percepta/releases/latest) 下载 `Percepta-Setup-版本号.exe` 装上。不需要管理员权限，以后有新版本时，设置里点一下就能更新。

安装包还没有代码签名，所以 Windows 可能会弹出“已保护你的电脑”。点 **更多信息**，再点 **仍要运行** 就好。

第一次使用得配对一下。

首先，你先这样——在 CSP 里打开 **文件 > 连接智能手机**，让二维码显示在屏幕上。

然后，你再这样——在 Percepta 里点右上角的齿轮，再点 **扫描屏幕二维码**。

最后，看到状态变成绿色的 **已连接** ——enjoy！

以后每次启动都会自动连接，这点不用担心~

## 优异的窗口管理！

当 CSP 在前台的时候，它会保持置顶，而且不会抢焦点，你尽可以大胆地调色。相信我，它甚至不会让你的快捷键失效~

当 CSP 不在前台呢...当然就不会自动置顶啦，总有个窗口占着位置多烦！

### 但是，马也有失前蹄的时候...

因为作者用的是 Wacom 的板子和驱动，而且是针对不同的软件设置了不同的按键映射。所以板子的映射会因为操作的软件变化而跑掉（这让作者蛮火大的，真的）。

当然，解决方法也很简单粗暴——点一下 CSP 的标题栏就好了。所以 Percepta 会在你抬笔之后替你点一下。这个功能是默认启用的，当然你也可以在设置里关掉——嗯...至少在 Wacom 面前把这个功能关掉不一定会有什么好事...

啊另外补充一点，目前这个功能只在 Wacom 上验证过，其他品牌的表现不好说。CSP 全屏或者隐藏了标题栏的时候点不到，这个办法就不起作用了。（话说 CSP 有全屏模式吗...作者怎么不记得有这回事儿...）

## 其他你可能想知道的

- 首先！**不要点 CSP 里的手机图标来断开。** 据说这样会让保存的配对失效，只能重新扫码。要是想断开的话，去 Percepta 的设置里点就好了。
- **这不是官方功能。** 所以万一哪天亖了也是有可能的（大雾）。Percepta 用的是 CSP 给手机准备的“连接智能手机”通道，协议没有公开，所以 CSP 哪天更新了，它也可能哪天就连不上了。这个时候要干什么？——对啦，赶紧提 issue 敲作者更新！
- **一次只能连一个。** Percepta 连着的时候，手机端应该就连不上了。
- **文档的色彩配置文件还没适配。** 协议只能传数值，色彩空间真管不了，所以如果文档用的是 Adobe RGB 这类配置文件，这边显示的颜色和实际的会有偏差。
- **数据都在本地。** 配对信息、颜色、设置、窗口布局和连接日志都放在 `%APPDATA%\Percepta`。扫二维码时的截屏只留在内存里，用完就没了。唯一会连外网的是启动时问一下 GitHub 有没有新版本，不想要的话可以在设置里关掉。

## 自己编译

想自己动手的话，需要 [Rust](https://www.rust-lang.org/tools/install) 和 Visual Studio 的 C++ 生成工具（有几个依赖要编译 C 代码）。

```bash
cargo build --release
```

编译结果在 `target/release/percepta.exe`。
